# Support Ticket Classification Engine

An automated machine learning system designed to parse, clean, and classify incoming customer support tickets into designated operational queues (**Billing**, **Technical**, **HR**, **General**).

## Overview

- **Feature Extraction**: TF-IDF N-gram Vectorization.
- **Classification Model**: Regularized Logistic Regression with balanced class weights.
- **Client Deployment**: Static Netlify web interface with embedded inference.
- **CLI Execution**: Instant command-line execution and training script.
